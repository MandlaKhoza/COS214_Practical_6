Detailed Description

Proxy of the Proxy pattern: controls who may view an account.

On display() it works out the requester's access level, logs the attempt, and only then loads the real account. A denied request never loads it. Access: the owner sees the full account, staff see the full account plus internal notes, auditors see a summary with a masked id, anyone else is denied.
